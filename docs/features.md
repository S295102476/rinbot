# 功能与指令

本文对应公开版默认能力。群内发送 `#指令一览` 查看菜单；扩展命令是否可用取决于管理员是否完成配置。模型工具执行受权限、群设置和配额控制。

## 聊天、记忆与日常

| 入口 | 作用 |
| --- | --- |
| `@机器人 <内容>` | 根据上下文和当前人格回复 |
| `@机器人` 并附图 | 识图或评论，需支持图片的模型 |
| `#翻译 <内容>。<语言>` | 基础翻译，例如 `#翻译 你好。日语` |
| `#我的记忆` | 查看机器人记住的个人信息 |
| `#清除历史` / `#清除历史 <QQ号>` | 管理员清除自己或指定用户的对话历史 |
| `#签到` | 每日签到与卡片 |
| `#好感度` / `#查询好感度` | 查看本群好感度 |
| `#娶群友` | 每日随机匹配群友 |
| `#值班表` / `#值班表 下周` | 查看当前或下一周排班 |

群聊中的长期记忆、摘要和人格关系可以在控制台管理。模型回复取决于接口能力与上下文，不保证每条消息都触发工具，也不把文字回答视为操作成功。

## 人格与管理控制台

| 页面 | 管理内容 |
| --- | --- |
| 运行概览 | 运行状态、群聊活动、配额与调用概况 |
| 群聊管理 | 添加群、回复策略、群级设置与活动查看 |
| Agent 设置 | 全局行为、模型使用与工具相关选项 |
| 表情库 | 查看、筛选、分类、编辑和删除表情 |
| 人格管理 | 当前人格切换、文档编辑、修订与切换记录；值班日历只读 |
| 记忆与关系 | 用户及群记忆、摘要、好感度和关系记录 |
| 请求记录 | 模型调用状态与用途 |
| 操作审计 | 管理员变更记录 |

内置人格：`rin`（远坂凛）、`eres`（艾蕾）、`ishtar`（伊什塔尔）。角色文档是可以修改的示例设定，不包含原部署者的私人人物关系。各人格拥有独立的好感度与关系状态；自动值班和手动切换共用当前人格状态。

管理员也可以私聊执行 `#agent persona reload` 刷新人设，或 `#agent persona switch eres 切换原因` 切换人格。人格切换作用于全局，切换前请留意其他群的当前对话。

## 六种小游戏

| 游戏 | 开始方式 | 说明 |
| --- | --- | --- |
| 五子棋 | `#五子棋 对战` / `#五子棋 双人` | 娱乐人机或群友对战，高级难度需 Rapfi |
| 井字棋 | `#井字棋 对战` / `#井字棋 @群友` | 本地规则与人机逻辑 |
| 象棋 | `#象棋 双人` / `#象棋 对战` | 人机需要 Fairy-Stockfish |
| 围棋 | `#围棋 13路 @群友` / `#围棋 对战` | 支持 9 / 13 / 19 路，人机需要 KataGo 和模型 |
| 成语填空 | `#成语填空 单人` / `#成语填空 抢答` | 离线题库，直接回复完整四字成语 |
| 猜数字 | `#猜数字 单人` / `#猜数字 抢答` | 四位不重复数字，使用 `#猜 1234` |

直接发送游戏名（例如 `#围棋`）只显示帮助，不开局。`#小游戏` 查看菜单，`#加入游戏` 接受邀请，`#棋盘` 查看局面，`#认输` 或 `#结束游戏` 结束。象棋可用 `#走棋 炮二平五`，其他棋类可用 `#落子 D4`；实际坐标规则以游戏帮助为准。

每群共用一个活动游戏。引擎未配置时，不会调用聊天模型冒充棋类引擎。引擎安装见[扩展说明](extensions.md#棋类引擎)。

## COC 跑团

`.help` 查看完整指令。常用入口包括 `.r 3d6+2` 掷骰、`.ra 侦查 60` 检定、`.coc` 生成角色、`.st 侦查:70` 设置属性、`.sc 1/1d6` 理智检定和 `.jrrp` 今日人品。

## 可选功能与状态

| 功能 | 入口示例 | 状态与前提 |
| --- | --- | --- |
| 联网搜索 | `#搜索 <问题>`、`#清除搜索` | 默认关闭；需搜索后端与凭据 |
| AI 绘图 / 编辑 | `#图片生成`、`#图片编辑`、`#手办化`、`#高质量化` | 默认关闭；需兼容图片生成接口 |
| NovelAI 绘图 | `#生图 <提示词>` | 默认关闭；需对应凭据 |
| Pixiv | `#涩图 <标签>`、`#p日榜`、`#p周榜` | 默认关闭；需凭据及可用网络 |
| 链接解析 | 发送支持平台链接 | 默认关闭；依赖对应平台与网络 |
| GBVSR | `#GB 帮助`、`#GB使用率` | 默认关闭；帧数查询需另行抓取数据 |
| Core 游戏查询 | `ww帮助`、`zzz帮助` 等 | 默认关闭；另装 Core 与对应插件 |
| 搜图 / 搜本子 | `#搜图`、`#搜本子` | 暂不可用，不属于可验收功能 |
| 尖塔百科 | `#尖塔` | 暂停维护，不纳入默认部署 |
| 私聊开发 Agent | `#开发` | 默认关闭；仅供已配置管理员，修改须经过审批 |

菜单可能展示未启用的扩展入口；部署者以配置和此表为准。Core 的游戏范围、账号绑定方式与可用指令由实际安装的插件决定。
