# RinBot 首个完整公开版 · 2026-10-08

RinBot 现已整理为可自行部署的 QQ 群聊机器人：提供 Web 管理控制台、多人格与长期记忆、表情管理、日常互动和小游戏。项目公开地址为 [S295102476/rinbot](https://github.com/S295102476/rinbot)。

本说明对应首个完整公开版 **v1.0.0**。此次发布包含 Git 历史清理，旧克隆请按下方迁移步骤重新同步。

## 本版内容

- **八页 Web 控制台**：运行概览、群聊管理、Agent 设置、表情库、人格管理、记忆与关系、请求记录、操作审计，支持明暗主题与窄屏访问。
- **多人格与记忆**：凛、艾蕾、伊什塔尔切换，独立好感度与关系，自动值班，角色文档编辑和修订。公开人设清除原部署者的私人关系，不分发用户档案。
- **群聊与日常**：上下文对话、模型支持时的识图、基础翻译、签到、值班表、表情收集；新群默认仅 @ 回复，可按群开启主动接话。
- **六种小游戏与 COC 骰子**：五子棋、井字棋、象棋、围棋、成语填空、猜数字；外部棋类引擎分别配置。
- **可配置的完整部署**：Docker Compose 初始化，Bot / MySQL / Redis / MinIO 四服务，自动构建控制台，持久化配置与数据，公开配置模板及依赖锁定文件。
- **按需启用外部能力**：搜索、绘图、Pixiv、链接解析、GBVSR 和 Core 桥接默认关闭。聊天模型的接口协议明确配置，默认使用 Chat Completions 兼容接口。
- **公开介绍与维护**：中文首页、艾蕾头像、用户与开发文档、贡献指南、第三方说明，以及后端、浏览器和部署检查。

完整功能与依赖见[功能指令文档](https://github.com/S295102476/rinbot/blob/main/docs/features.md)和[扩展说明](https://github.com/S295102476/rinbot/blob/main/docs/extensions.md)。

## 首次安装

推荐 Linux x64 + Docker Compose v2。准备自己的模型完整请求地址、API Key、模型名、管理员 QQ、允许群和控制台密码，然后执行：

```bash
git clone https://github.com/S295102476/rinbot.git
cd rinbot
docker compose run --rm init
docker compose up -d --build
```

控制台默认位于 `http://127.0.0.1:8080/admin/`，用户名 `admin`。在自己的 OneBot v11 客户端登录 QQ，配置反向 WebSocket 与生成的 Token，再分别确认服务启动、控制台登录、真实 QQ 回复和图片显示。

详细步骤见[首页快速部署](https://github.com/S295102476/rinbot/blob/main/README.md#快速部署)、[部署与维护](https://github.com/S295102476/rinbot/blob/main/docs/deployment.md)和[配置参考](https://github.com/S295102476/rinbot/blob/main/docs/configuration.md)。

## 旧版本迁移与历史清理

发布分支历史已清除发现的旧私人配置、硬编码凭据、私人关系和账号默认值，原私有备份保留在维护者本机。原部署者已确认旧绘图凭据失效或撤销；历史清理不能撤回他人曾下载的副本。

这次更新涉及历史重写，旧克隆请重新获取仓库：

1. 将未提交修改导出到私有位置，备份自己的配置、数据库、图片与人格修改。
2. 在新目录重新克隆上述仓库，不把旧 `.git`、旧分支或旧标签推回公开仓库。
3. 生成新配置并按公开模板迁移必要参数，避免直接套用已撤销的凭据或旧服务地址。
4. 从备份筛选代码修改，以补丁形式应用到新克隆，复查是否带入密钥或个人资料。
5. 验证后再切换现有服务；初始化流程不会自动导入原私人数据，旧数据库迁移需按实际版本另行核对。

Core 改为可选外部服务，保留自己的 Core 部署并填写桥接 URL，不将其源码、Cookie 或数据目录复制进主仓库。

## 当前限制

- 搜索、绘图、Pixiv、链接解析、Core 和 GBVSR 需要自己的服务或数据，外部平台变化可能影响可用性。
- 象棋 / 围棋人机与五子棋高级难度需要单独安装引擎；约 4 GB 的 GBVSR 图片不随源码分发，可按文档抓取。
- 控制台值班日历只读，搜图和搜本子暂不可用，尖塔百科暂停维护。
- 首页截图待补，已有截图文件约定，不引用不存在的占位图片。
