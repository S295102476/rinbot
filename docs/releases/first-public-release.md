# RinBot 完整公开版

本版本把已有 QQ 机器人扩展为可自行部署的完整项目，包含 Web 控制台、多人格、长期记忆、小游戏与可选外部服务。

## 新增与整理

- 八页 Web 控制台：运行概览、群聊管理、Agent 设置、表情库、人格管理、记忆与关系、请求记录和操作审计。
- 凛、艾蕾、伊什塔尔的人格文档、独立关系与自动值班；公开示例清除原部署者的私人关系，不分发用户档案。
- 六种小游戏与 COC 骰子，外部棋类引擎单独启用。
- Docker Compose 初始化与持久化部署，自动构建前端，提供公开配置模板和依赖锁定文件。
- 模型接口协议显式配置，默认使用一组 Chat Completions 兼容接口；外部扩展默认关闭。
- 中文项目首页、头像、配置与使用文档、第三方说明和持续检查。实际截图后续补充。

## 首次安装

按照[首页快速部署](../../README.md#快速部署)，完成初始化并运行四个服务，再接入自己的 OneBot v11 客户端。服务启动、控制台登录与真实 QQ 回复分别验证。

## 旧版本迁移与历史清理

本次公开整理需要清理旧提交中的私人配置与硬编码凭据。已公开凭据应在对应服务更换，删除历史不能撤回他人已下载的副本。

当维护者完成并宣布历史重写后，旧克隆请采用以下迁移方式：

1. 将未提交修改导出到私有位置，同时备份本地配置、数据库、图片和角色修改。
2. 在新目录重新克隆仓库，不把旧 `.git`、旧分支或旧标签推回公开仓库。
3. 使用初始化器生成新配置，对照模板迁移必要业务参数；不要直接公开旧配置。
4. 在私有备份中筛选代码修改，以补丁形式应用到新克隆，并检查补丁是否带入密钥或个人资料。
5. 验证新环境后再决定是否切换服务；原数据库迁移需结合实际旧版本确认，首次部署流程不会自动导入私人数据。

Core 从主仓库移为可选外部服务。保留现有 Core 部署并设置桥接 URL，不要将整个 Core 数据目录复制进本仓库。

## 可选能力与当前限制

- 搜索、绘图、Pixiv、链接解析、Core 和 GBVSR 需要额外配置；外部服务变化可能影响这些能力。
- 象棋 / 围棋人机与五子棋高级难度需要单独安装引擎，GBVSR 大图片不随源码发布。
- 控制台值班日历只读。搜图、搜本子暂不可用，尖塔百科暂停维护。
- 首页截图尚待补充，当前没有伪造的功能截图或失效占位图。
- 头像等第三方素材独立于代码许可证，详见[第三方说明](../../THIRD_PARTY_NOTICES.md)。

## 发布验收记录

发布者应在实际 Release 中填写测试环境、提交号与结果，包括后端测试、前端构建、浏览器流程、干净克隆部署、真实 QQ 回复、图片显示、重启持久化及公开历史扫描。没有验证的项目应明确标为未验证，不能以 CI 通过代替真实 QQ 接入测试。
