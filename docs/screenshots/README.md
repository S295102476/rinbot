# 项目截图

图片放在此目录并通过相对路径加入根 README，推荐 PNG 或 WebP。尽量将单张控制在 1 MB 左右；需要展示完整操作时可用短 GIF，但同时保留静态封面。

| 建议文件名 | 内容 | 建议取景 |
| --- | --- | --- |
| `console-overview.png` | 控制台运行概览 | 第一张主图，显示导航、概览卡片和图表 |
| `qq-chat.png` | QQ 对话 / 识图 | 几轮连贯的真实使用示例 |
| `personas-roster.png` | 人格管理和值班表 | 控制台页面与 QQ 值班图片可拼图 |
| `minigames.png` | 小游戏菜单与棋盘 | 展示一种棋局和一种文字游戏 |
| `memes.png` | 表情库 | 展示筛选、分类和管理能力 |
| `memory-relations.png` | 群聊设置 / 记忆与关系 | 使用专门的演示数据 |

截图使用演示 QQ、演示群和演示聊天，不展示 Access Token、接口密钥、Cookie、真实用户记忆或私人关系。截取控制台时留出足够空间，不把浏览器地址栏中的敏感查询参数带进去。

提供图片后，将根 README 的「界面预览」替换为实际引用，例如：

```markdown
![控制台运行概览](docs/screenshots/console-overview.png)
```

当前尚未加入实际截图，README 不引用不存在的图片。头像单独保存在 `docs/assets/rinbot-avatar.png`。
