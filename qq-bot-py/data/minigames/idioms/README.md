## 首版筛选与出题

1. 只保留四个基本区汉字的条目；去除首尾空白；重复词取最大 DF。
2. 应用 `exclusions.tsv`：逐行记录本游戏的编辑排除及原因。它是游戏选题政策，不是权威成语正误判定；例如普通新闻描述、行业术语、口号性动宾搭配不作为首版题目。已逐项复核首版高频候选，未将繁体字自动转成简体或擅自改写词条。
3. 按 DF 降序、同频按词条排序，取前 1000 条作为随机出题主词。当前 59 项编辑排除后，完整清洗词库为 7815 条，1000 项池的最后一项为「不进则退」。不随聊天内容生成新题。
4. 每题随机挖去两个字，涵盖六种位置组合，例如「春□花□」。完整清洗词库（包括低频词）构建双空掩码答案索引，多解全部写进题目 `answers`，不能只判主词。唯一解题面优先。
5. 同局已展示的题面和所有接受答案都进入排除集合。题目持久化后以保存的答案快照判分，未来更新词库不改变旧题答案。

`normalise_answer` 只剥除外围空白／标点，要求剩余为完整四字汉字串；不提取句中成语、不改同音错字、不做简繁转换。判题仍是精确匹配题目保存的 `answers`，四个汉字本身并不等于正确答案。

## 更新与故障

- `load_default()` 相对代码所在的项目根目录找数据，不依赖进程当前目录。测试可用 `load_default(root=临时项目根目录)`；也可直接注入小样本 `IdiomBank`。
- 启动离线检查原数据和许可 SHA256；允许 Windows/Linux 的纯 LF/CRLF 换行差异。缺文件、坏格式、坏来源信息或实质内容变化均抛出 `IdiomBankError`，调用方应只停用成语，不能连带停用棋类。
- 可在项目根执行 `.venv/bin/python tools/check_idioms.py`，精确检查缺失文件、格式、版本及哈希；此工具不读密钥、不联网、不操作数据库。必须一起上传 `THUOCL_chengyu.txt`、`LICENSE`、`source.json`、`exclusions.tsv`，不能只上传插件代码。
- 新代码不会强行改写旧局：旧单人已保存的十题单空快照继续有效；旧抢答当前单空题结束后，下一题采用双空。
- 要调整游戏选题，编辑 `exclusions.tsv` 并保留排除原因；不要直接改原词表。重启后新题采用新名单，已有题目用快照。
- 要升级上游词表，必须重新核实 commit、哈希、许可与前 1000 高频候选，更新 `source.json`、代码中的固定哈希和测试；不能只替换原文件。
- 本目录不含第三方整套辞书释义，不构成对所有词条语义或词典地位的保证。
