# 控制台外观与布局

控制台左侧「外观设置」，或右上角调色板入口，可调整整个工作区的外观。设置即时生效并保存在当前浏览器；重新登录或刷新不会重置。不同浏览器分别设置，清除站点数据后会恢复默认。

## 可调整内容

- 浅色、深色、跟随系统；顶部日月按钮仍可快速切换。
- 纯色或毛玻璃面板，面板不透明度与背景模糊强度。
- 海洋蓝、樱花粉、星云紫、森林绿、日落橙五种强调色。
- 三张随构建打包的原创 SVG 星空壁纸：深空星河、紫雾星云、极光山谷。没有外部图床依赖。
- 本地 JPG、PNG、WebP 自定义壁纸，最大 15 MiB。选择后自动处理为最长边不超过 2560px 的图片，保存在浏览器 IndexedDB；不会上传到服务器。
- 壁纸遮罩，以及「星河夜航」「星云漫游」「极光微光」「简洁日光」四套预设。

「恢复默认」重置当前外观，但保留已选择的自定义图片，方便再次使用。要删除图片，在「背景」中点击「移除自定义壁纸」。存储被浏览器禁用或空间不足时，页面会给出说明；基础控制台仍可使用。浏览器不支持毛玻璃效果时，使用不透明面板保证文字可读。

## 新页面布局

用途路由、长期记忆、整理任务与开发任务统一使用卡片、表单标签和页面间距。桌面端开发任务分为列表与详情，较窄屏幕自动改为上下布局。较宽表格、检查输出、证据 JSON 和实际补丁在各自区域滚动，长需求、模型说明与错误文本不会撑开页面。

开发任务的「模型说明」与「完整差异」分别展示。任务显示「分析完成」但没有实际补丁时，会明确提示不能应用；模型口头输出的代码或 diff 不等于已调用补丁工具。审批仍要求检查通过、完整差异存在、管理员勾选审阅，并由后端校验版本和权限。

## 上传到现有服务器

本地构建：

```powershell
cd qq-bot-py/console
npm run build
```

将 `console/dist/assets/` 中的全部文件通过 SFTP 上传到服务器项目对应的 `console/dist/assets/`，然后上传 `console/dist/index.html` 到同名位置。先上传资源，再上传首页，避免新首页引用尚未上传的文件。已有手动部署只更新外观时，不需要修改配置、重新构建开发检查镜像或迁移数据库；Docker 部署需要重建机器人镜像。

现有后端会直接读取磁盘上的静态文件。上传完成后，在浏览器按 `Ctrl+F5` 刷新即可；不需要重启机器人。如果前面尚未开启开发功能，那是另一项配置步骤，与本次外观更新无关。

浏览器验证使用模拟 API 与演示数据，不读取生产账号或聊天内容：

```powershell
cd qq-bot-py/console
npm test
```

本地图片存储使用 [IndexedDB](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API/Using_IndexedDB)，毛玻璃面板使用 [backdrop-filter](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/backdrop-filter)。默认 SVG 的资源说明见 `console/src/assets/wallpapers/README.md`。
